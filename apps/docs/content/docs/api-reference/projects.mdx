Projects are the top-level resource in UploadKit. Each project has its own API keys, file routes, files, and usage quotas. All file operations are scoped to a project via the API key used.

## Project Object

```json
{
  "_id": "65f1a2b3c4d5e6f7a8b9c0d1",
  "name": "My Application",
  "slug": "my-application-a1b2c3",
  "userId": "65f0...",
  "createdAt": "2026-04-08T12:00:00.000Z",
  "updatedAt": "2026-04-08T12:00:00.000Z"
}
```

---

## GET /api/v1/projects

Returns the project the API key belongs to (as a one-element list). API keys are scoped to a single project, so other projects of the same account are never listed.

**curl example:**

```bash
curl https://api.uploadkit.dev/api/v1/projects \
  -H "Authorization: Bearer uk_live_xxxxxxxxxxxxxxxxxxxxx"
```

**Response:**

```json
{
  "projects": [
    {
      "_id": "65f1a2b3c4d5e6f7a8b9c0d1",
      "name": "My Application",
      "slug": "my-application-a1b2c3",
      "userId": "65f0...",
      "createdAt": "2026-04-08T12:00:00.000Z"
    }
  ]
}
```

---

## GET /api/v1/projects/me

Returns the project the API key belongs to and the account plan. Use it to check that a key works before uploading.

```bash
curl https://api.uploadkit.dev/api/v1/projects/me \
  -H "Authorization: Bearer uk_live_xxxxxxxxxxxxxxxxxxxxx"
```

**Response:**

```json
{
  "project": {
    "_id": "65f1a2b3c4d5e6f7a8b9c0d1",
    "name": "My Application",
    "slug": "my-application-a1b2c3",
    "tier": "PRO"
  },
  "tier": "PRO"
}
```

## POST /api/v1/projects

Project API keys cannot create projects. The request is rejected with `403 FORBIDDEN`; create projects from the [dashboard](/docs/dashboard/projects).

**Error cases:**

| Code | HTTP | Cause |
|------|------|-------|
| `FORBIDDEN` | 403 | Any call with a project API key |

---

## PATCH /api/v1/projects/:id

Update a project's name.

**Request body:**

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | No | New project name (1–100 characters) |

**curl example:**

```bash
curl -X PATCH https://api.uploadkit.dev/api/v1/projects/65f1a2b3c4d5e6f7a8b9c0d1 \
  -H "Authorization: Bearer uk_live_xxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Renamed Application"
  }'
```

**Response:** `{ "project": { ... } }` with the updated project.

**Error cases:**

| Code | HTTP | Cause |
|------|------|-------|
| `NOT_FOUND` | 404 | Project does not exist or belongs to a different account |

---

## DELETE /api/v1/projects/:id

Delete a project. All API keys associated with the project are revoked; uploaded files and file routes remain in storage.

<Callout type="warn">
  Deleting a project revokes **all** API keys that target it. Any service using those keys will begin receiving `401 UNAUTHORIZED` immediately.
</Callout>

**curl example:**

```bash
curl -X DELETE https://api.uploadkit.dev/api/v1/projects/65f1a2b3c4d5e6f7a8b9c0d1 \
  -H "Authorization: Bearer uk_live_xxxxxxxxxxxxxxxxxxxxx"
```

**Response:**

```json
{ "ok": true }
```

**Error cases:**

| Code | HTTP | Cause |
|------|------|-------|
| `NOT_FOUND` | 404 | Project does not exist or belongs to a different account |

<Callout type="info">
  You can also manage projects from the [Projects](/docs/dashboard/projects) section of the dashboard.
</Callout>
